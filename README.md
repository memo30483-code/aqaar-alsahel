# عقار الساحل

MVP لسوق عقاري مفتوح لمدن الساحل الجديدة (دمياط الجديدة والمنصورة الجديدة).

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## التقنيات

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Leaflet.js (خريطة تفاعلية)

## الصفحات

- `/` — الرئيسية: هيرو، فلتر، خريطة، جريد عقارات
- `/add-property` — نموذج إضافة عقار (رفع وهمي بدون حفظ فعلي)
